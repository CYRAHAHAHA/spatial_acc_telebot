BACKEND ENDPOINTS:

1. GET /api/status
   Returns Autodesk project info.
   Example response:
   {
     "user": "YR",
     "project_id": "abcd1234",
     "token": { "valid": true, "expiresAt": "2025-11-11T23:59:00Z", "expiresInMinutes": 50 },
     "env": { "region": "EMEA" },
     "message": "Connected"
   }

2. GET /api/preview/status_sets
   Returns a list of existing status sets.
   Example response:
   {
     "count": 2,
     "items": [
       {
         "statusSetId": "100",
         "name": "Design Review",
         "statuses": [
           { "statusId": "1", "label": "Pending", "description": "Waiting for review" },
           { "statusId": "2", "label": "Approved", "description": "Review complete" }
         ]
       }
     ]
   }

3. GET /api/preview/custom_fields
   Returns existing custom fields.
   Example response:
   {
     "count": 1,
     "items": [
       {
         "id": "cf_001",
         "displayName": "Priority",
         "dataType": "string",
         "requiredOnIngress": false,
         "enumValues": []
       }
     ]
   }

4. GET /api/preview/categories
   Returns existing categories.
   Example response:
   {
     "count": 3,
     "items": [
       { "categoryId": "cat_01", "categoryName": "Electrical", "parentId": null },
       { "categoryId": "cat_02", "categoryName": "HVAC", "parentId": null }
     ]
   }

5. POST /create_status_sets_from_json
   Accepts JSON array of status set objects.
   Example payload:
   [
     { "name": "New Status Set", "statuses": [{ "label": "Pending" }, { "label": "Done" }] }
   ]
   Returns: { "created": 1 }

6. POST /create_custom_fields_from_json
   Accepts JSON array of custom field objects.
   Example payload:
   [
     { "displayName": "Priority", "dataType": "enum", "enumValues": [{"label": "High"},{"label":"Low"}], "requiredOnIngress": true }
   ]
   Returns: { "created": 1 }

7. POST /create_categories_from_json
   Accepts JSON array of category objects.
   Example payload:
   [
     { "categoryName": "Mechanical", "parentId": null, "statusSetId": "100" }
   ]
   Returns: { "created": 1 }
